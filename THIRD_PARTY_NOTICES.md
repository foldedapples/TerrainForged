## Ported code (v0.3+)

`common/src/main/java/net/freak4u/terrainforged/engine/rtf/**` is a port of ReTerraForged's released 1.20.1 branch
("RTF 0.0.6", revision `29239f1`, `common/src/main/java/raccoonman/reterraforged/`), itself derived from
TerraForged. Each file carries a header naming its origin and licence. Ported parts:

| Area | RTF source (`world/worldgen/...` unless noted) | Changes in TerrainForged |
|---|---|---|
| Noise library | `noise/**` | Minecraft codecs/registries removed; plain Java |
| Cells, heightmap, levels | `cell/Cell.java`, `cell/heightmap/**` | no cell pools; `WorldLookup` uncached; data-pack noises inlined (ground = sea level / terrain scale, biome edge shape from the preset) |
| Continents | `cell/continent/**` | thread-local scratch cells instead of pooled resources |
| Terrain types, regions, blending | `cell/terrain/**` | codecs removed |
| Rivers, lakes, wetlands | `cell/rivermap/**` | expiring concurrent cache replaced by a bounded LRU |
| Climate & biome types | `cell/climate/**`, `cell/biome/type/BiomeType.java` | `biomes.png` precomputed into a table with RTF's own nearest-colour rule (no `java.awt` at runtime) |
| Tiles & filters | `densityfunction/tile/**`, `WorldErosion.java`, `WorldFilters.java`, `cell/filter/**` | synchronous tile generation; TerrainForged caches finished tiles |
| Biome parameters | `biome/{Continentalness, Erosion, Weirdness, Temperature, Humidity, ...}` | none |
| Settings | `raccoonman/reterraforged/data/worldgen/preset/settings/*` | caves/structures settings dropped; `terrainScaler()` not capped at 256 |
| Decorators | `feature/ErodeFeature.java`, `feature/DecorateSnowFeature.java`, `feature/ColumnDecorator.java` | decision logic in `engine/worldgen/SurfaceDecorator.java`, block placement in `common-mc/.../ErodeFeature.java` and `DecorateSnowFeature.java` |
| Vanilla mapping | `densityfunction/CellSampler.java` (`Field.CONTINENT`) | reimplemented in `RtfTerrain.continentalness` |

v0.2 had ported RTF's unfinished 1.20.2 rework branch (`98fd3a2`); that port was replaced.

## Adapted algorithms

TerrainForged's own code (engine wrapper and caching, settings, preview renderer, Minecraft integration, density
function, world presets and the world-creation UI) is a new implementation; see
`docs/ENGINEERING.md`. Reference revisions inspected: TerraForged `6dd607e` (2022-06-16), ReTerraForged
`29239f1` (1.20.1, 2024-01-09) and `98fd3a2` (1.20.2, 2024-02-21).

The shipped world-preset JSON embeds Minecraft 1.21.11's overworld noise-router composition and surface rule
(Mojang data), modified to call TerrainForged; it is generated by `tools/generate_presets.py`.
